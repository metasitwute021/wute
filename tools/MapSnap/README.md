# MapSnap + Range Finder

เครื่องมือจับภาพหน้าจอ วางจุด และ**วัดระยะเป็นเมตร**บนภาพแผนที่ แบบแยกจากเกม
ใช้เฉพาะภาพหน้าจอ: ไม่อ่านหน่วยความจำเกม ไม่ส่งคำสั่งเข้า PUBG และไม่แก้ไฟล์เกม

## วิธีใช้

1. ดับเบิลคลิก `RunMapSnap.cmd`
2. กด **ย่อไปที่เกม** แล้วเปิดแผนที่ PUBG ตามปกติ (ซูมแมพให้เห็นเส้นตารางอย่างน้อย 2–3 ช่อง)
3. กด **F8** เพื่อจับภาพหน้าจอ โปรแกรมจะเด้งขึ้นมาพร้อมภาพ
4. **คาลิเบรตสเกล** (ครั้งแรกของแต่ละระดับซูม): คลิกบนเส้นตารางของแมพ 2 เส้นที่ติดกัน
   — ช่องเล็ก 1 ช่อง = 100 ม. เสมอ ถ้าลากข้ามหลายช่องให้แก้ตัวเลขในช่อง "ระยะที่ลาก"
   เป็นระยะรวม (เช่น 5 ช่อง = 500) ยิ่งลากไกลยิ่งแม่น
5. คลิกซ้ายจุดแรก = **ตำแหน่งเรา** (วงกลมฟ้า), คลิกต่อ = จุดที่มาร์ค (กากบาทส้ม)
   ระยะเป็นเมตรขึ้นบนเส้นทันที พร้อมกล่องสรุปมุมซ้ายบน:
   ระยะรวม / ยิงตรง / เวลาวิ่ง / ค่า Zeroing / ระยะตั้งปืนค. (mortar ยิงได้ 100–700 ม.)
6. คลิกขวาใกล้จุด = ลบจุดนั้น, `Delete` = ลบจุดล่าสุด, `C` = ล้างทั้งหมด, `K` = คาลิเบรตใหม่
7. **บันทึก PNG** ได้ภาพพร้อมเส้นวัดและกล่องสรุป เอาไว้ส่งให้เพื่อนในทีม

เคล็ดลับ: ถ้ากด F8 ครั้งถัดไปโดย**ไม่เปลี่ยนระดับซูมแมพ** สเกลเดิมยังใช้ได้
โปรแกรมจะจำไว้ให้ ไม่ต้องคาลิเบรตซ้ำ

ข้อจำกัด: ภาพเป็น snapshot ณ ตอนกด F8 ไม่ใช่การอ่านข้อมูลจากเกมแบบต่อเนื่อง
จึงปลอดภัยและไม่ดัดแปลงไฟล์ PUBG. หากเกมแสดงภาพดำ ให้เล่นแบบ Borderless/Windowed
แล้วลองใหม่ เพราะบางโหมด fullscreen ป้องกันการจับภาพหน้าจอ.
