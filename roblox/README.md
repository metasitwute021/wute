# แมพ Roblox: เกาะ + Obby

สคริปต์ `MapBuilder.server.lua` สร้างแมพทั้งหมดให้อัตโนมัติ ไม่ต้องวางชิ้นส่วนเองทีละชิ้น

## ในแมพมีอะไรบ้าง

| ส่วน | รายละเอียด |
|---|---|
| 🏝️ เกาะ | พื้นหญ้า (Terrain) ขอบเป็นทราย มีเนินหินรอบเกาะ ล้อมด้วยทะเล |
| 🏠 Lobby | ลานหินอ่อน จุดเกิด (สีฟ้า) เสา 4 มุม ป้ายต้อนรับ และต้นไม้ 25 ต้น |
| 🟩 แท่นเริ่ม | แท่นเขียวใน Lobby: เหยียบแล้ววาร์ปขึ้นไปที่ Obby บนฟ้า |
| 🟢 ด่าน 1 | กระโดดข้ามแท่นซิกแซก |
| 🔵 ด่าน 2 | เดินบนคานแคบ ข้างล่างเป็นลาวา |
| 🟡 ด่าน 3 | แท่นเลื่อนซ้าย-ขวา |
| 🟣 ด่าน 4 | บันไดกระโดดขึ้นที่สูง |
| 🔴 ด่าน 5 | วิ่งผ่านก้อนลาวาที่เลื่อนขวางทาง |
| 🏆 เส้นชัย | แท่นทองพร้อมถ้วยรางวัล |

ระบบเกมที่มีให้:
- **Checkpoint**: แตะแล้วจะเกิดใหม่ที่ด่านนั้น
- **Leaderboard**: ค่า `Stage` แสดงบนกระดานมุมขวาบน
- **ลาวา / ตกจาก Obby**: ตัวละครตาย แล้วเกิดใหม่ที่ checkpoint ล่าสุด

## วิธีใช้ (แนะนำ)

1. เปิด **Roblox Studio** แล้วเลือกเทมเพลต **Baseplate**
2. ในหน้าต่าง **Explorer** คลิกขวาที่ **ServerScriptService** แล้วเลือก **Insert Object → Script**
3. ลบโค้ดเดิมใน Script ทิ้ง แล้ววางโค้ดทั้งหมดจาก `MapBuilder.server.lua`
4. กด **Play** (F5) แมพจะสร้างเองทันทีและเล่นได้เลย

> วิธีนี้แมพจะถูกสร้างใหม่ทุกครั้งที่เซิร์ฟเวอร์เริ่ม ระบบ checkpoint, ลาวา และแท่นเลื่อนจะทำงานครบ

## อยากดูหรือแก้แมพในโหมดแก้ไข (ไม่ต้องกด Play)

1. เปิด **View → Command Bar**
2. วางโค้ดทั้งไฟล์ลงใน Command Bar แล้วกด **Enter**
3. แมพจะโผล่ในโฟลเดอร์ `Workspace/GeneratedMap` ให้ขยับ แก้สี หรือแต่งต่อได้

⚠️ วิธีนี้สร้างแค่ **ชิ้นส่วน** ระบบลาวา, checkpoint และแท่นเลื่อนยังไม่ทำงาน
ถ้าจะเล่นจริงต้องใส่สคริปต์ไว้ใน ServerScriptService ด้วย (แต่สคริปต์จะสร้างแมพใหม่ทับตอนกด Play)

## ปรับแต่ง

แก้ค่าในตาราง `CONFIG` ที่ด้านบนของไฟล์:

| ค่า | ความหมาย |
|---|---|
| `IslandRadius` | ขนาดเกาะ |
| `TreeCount` | จำนวนต้นไม้ |
| `ObbyStart` | ตำแหน่งจุดเริ่ม Obby |
| `FallKillY` | ถ้าตกต่ำกว่าความสูงนี้ใต้ Obby จะตาย |
| `Seed` | เปลี่ยนเลขแล้วต้นไม้กับเนินเขาจะสุ่มตำแหน่งใหม่ |
| `ClearTerrain` / `RemoveBaseplate` | ตั้งเป็น `false` ถ้าไม่อยากให้ลบของเดิม |

สีของแต่ละด่านแก้ได้ที่ `ZONE_COLORS` ส่วนรูปแบบด่านแก้ได้ในฟังก์ชัน `buildObby()`

## เผยแพร่ให้เพื่อนเล่น

**File → Publish to Roblox** แล้วไปที่ **Game Settings → Permissions** ตั้งเป็น **Public**
