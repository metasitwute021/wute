# 🗺️ Fantasy World: แมพโลกกว้างแฟนตาซีสำหรับ Roblox

สคริปต์ `MapBuilder.server.lua` สร้างโลกทั้งใบให้อัตโนมัติ ไม่ต้องวางชิ้นส่วนเองแม้แต่ชิ้นเดียว

## 🌍 ในโลกนี้มีอะไรบ้าง

โลกกว้าง **3,072 × 3,072 studs** (เดินจากฝั่งหนึ่งไปอีกฝั่งหลายนาที) ใช้ **🌀 ลานวาร์ป** ในเมืองเพื่อเดินทางเร็ว

```
   🌋 ภูเขาไฟ          🏔️ เทือกเขาหิมะ + ศาลเจ้าน้ำแข็ง           ⛰️
   (มังกร)                (โกเลม, ค้างคาว)
                 💀 ประตูดันเจี้ยน
                    (มิโนทอร์)
   🏰 ปราสาท ─── 🏘️ เมือง + 🌀 ลานวาร์ป ─── 🌲 ป่ามหัศจรรย์ ─── 🌳 ต้นไม้โลก
                         │         ╲                          🧝 หมู่บ้านเอลฟ์
   👺 ค่ายก็อบลิน         │          🦴 ซากปรักหักพัง          (ป่าโบราณ)
                         │                    ╲
                         │                     🐍 หนองน้ำแม่มด
                      ⚓ ท่าเรือ
                  🌊 ทะเลล้อมรอบทั้งเกาะ 🌊
```

| 🏰 **ปราสาท** (ทิศตะวันตก) | กำแพงสูง (มีบันไดขึ้นไปเดินบนกำแพงได้), หอคอย 4 มุม, ธง, ห้องบัลลังก์ (นั่งบัลลังก์ได้) |

| 🏔️ **เทือกเขาหิมะ** (ทิศเหนือ) | สันเขาหลายยอด ยอดมีหิมะ, ศาลเจ้าน้ำแข็ง, **โกเลมหิน** และ **ค้างคาว** |
| ⛰️ **ยอดเขาเดี่ยว** | ภูเขาอีก 4 ลูกกระจายทั่วเกาะ |

| 🐍 **หนองน้ำแม่มด** (ตะวันออกเฉียงใต้) | แอ่งน้ำ ใบบัว ต้นกก ต้นไม้ตาย ไฟผี, **กระท่อมแม่มดบนเสา** มีหม้อยาเรืองแสง, **งูยักษ์** และ **สไลม์พิษ** |
| 💀 **ซากปรักหักพัง** | เสาหัก, หลุมศพ, คริสตัลต้องสาป, **โครงกระดูก**, **วิญญาณ**, **ค้างคาว** |
| ⚓ **ท่าเรือ** (ใต้สุด) | สะพานท่าเรือ, เรือใบ (นั่งได้), ประภาคาร |

### 🌀 ลานวาร์ป

ในเมืองมี **ลานวาร์ป** เป็นวงกลม **11 ประตู** เหยียบประตูไหนก็จะไปโซนนั้นทันที ทุกโซนมีประตูสีฟ้า **"🌀 กลับลานวาร์ป"** อยู่ข้างจุดที่โผล่ ส่วนดันเจี้ยนต้องวาร์ปไปที่ประตูดันเจี้ยน แล้วเหยียบประตูสีม่วงใต้ซุ้มหัวกะโหลกเพื่อลงไปข้างใน

### 🎨 กราฟิก: ธีมมืด เดินป่า

- ภาพโทนโพล้เพล้ มีหมอกหนา เมฆ และแสงอาทิตย์ส่องลอดเป็นลำ
- ของเรืองแสง (เห็ด คริสตัล โคมไฟ ไฟผี) มีแสงฟุ้ง
- **น้ำสะท้อนแสงเต็มที่** มีหิ่งห้อยลอยในป่า
- พื้นใช้ **Terrain ที่มีพื้นผิว (Texture)** เช่น หญ้า ดิน หิน หิมะ โคลน หินบะซอลต์ และลาวา
- ตึกและของต่าง ๆ ใช้วัสดุมีลาย เช่น ไม้ หินก้อน อิฐ และหินอ่อน
- ช่วงกลางวันผ่านเร็ว เวลาส่วนใหญ่จึงเป็นช่วงเย็นกับกลางคืน
- อยากได้ภาพสว่างแบบเดิม ให้ตั้ง `DarkTheme = false`

## 📖 วิธีใช้สำหรับมือใหม่ (ทีละขั้นตอน)

### ขั้นที่ 1: ติดตั้ง Roblox Studio

1. เข้าเว็บ **https://create.roblox.com** แล้วกด **Start Creating** เพื่อดาวน์โหลด Roblox Studio
2. ติดตั้งแล้วเปิดโปรแกรม
3. **Log in** ด้วยบัญชี Roblox เดียวกับที่ใช้เล่นเกม

### ขั้นที่ 2: สร้างเกมใหม่

1. ในหน้าแรกของ Studio กด **New** (หรือ **Create**)
2. เลือกเทมเพลต **Baseplate** (พื้นเรียบสีเทา)
3. รอสักครู่ จะเห็นพื้นสีเทากับจุดเกิด

### ขั้นที่ 3: เปิดหน้าต่างที่ต้องใช้

ไปที่แท็บ **View** ด้านบน แล้วกดเปิด:
- **Explorer**: รายการของทุกอย่างในเกม (ปกติอยู่ด้านขวา)
- **Output**: ช่องข้อความ ใช้ดูว่าสคริปต์ทำงานถึงไหน หรือมีปัญหาอะไร

### ขั้นที่ 4: ใส่สคริปต์สร้างแมพ

#### ✅ วิธีที่ 1 (แนะนำ ง่ายสุด): ใช้ไฟล์ `MapBuilder.rbxmx` ไม่ต้องก๊อปวาง

1. ดาวน์โหลดไฟล์ **`MapBuilder.rbxmx`** มาไว้ในคอมพิวเตอร์
2. ใน Studio ที่หน้าต่าง **Explorer** คลิกขวาที่ **ServerScriptService**
3. เลือก **Insert from File...**
4. เลือกไฟล์ `MapBuilder.rbxmx` แล้วกด **Open**
5. จะมี Script ชื่อ **MapBuilder** โผล่ใต้ ServerScriptService ใช้ได้ทันที

> หรือจะ **ลากไฟล์ `.rbxmx` ไปวางในหน้าต่าง Studio** ก็ได้ แล้วค่อยลาก Script ที่โผล่มาเข้าไปใน ServerScriptService

#### วิธีที่ 2: ก๊อปวางโค้ดเอง

1. ในหน้าต่าง **Explorer** หาบรรทัด **ServerScriptService**
2. เอาเมาส์ไปชี้ แล้วกดปุ่ม **➕** (หรือคลิกขวา → **Insert Object**)
3. เลือก **Script**
   > ⚠️ ต้องเป็น **Script** เท่านั้น ห้ามเลือก LocalScript หรือ ModuleScript
4. จะมีหน้าต่างโค้ดเปิดขึ้นมา พร้อมโค้ด `print("Hello world!")`
5. กด `Ctrl + A` แล้วกด `Delete` เพื่อลบโค้ดเดิมทิ้ง
6. เปิดไฟล์ `MapBuilder.server.lua` แล้วก๊อปโค้ด **ทั้งหมด** มาวาง (`Ctrl + V`)
7. (ไม่บังคับ) คลิกขวาที่ Script ใน Explorer → **Rename** แล้วตั้งชื่อว่า `MapBuilder`

> ⚠️ โค้ดยาว 3,500 บรรทัด ถ้าวางแล้วไม่ครบหรือวางไม่ได้:
> - เปิดไฟล์ด้วย **Notepad** หรือ **VS Code** (อย่าเปิดในมือถือหรือเว็บเบราว์เซอร์)
> - กด `Ctrl + A` เพื่อเลือกทั้งหมดก่อน แล้วค่อยกด `Ctrl + C`
> - วางใน **หน้าต่าง Script** (ไม่ใช่ Command Bar ที่อยู่ด้านล่าง)
> - เลื่อนไปดูบรรทัดสุดท้ายใน Studio ต้องเป็น `print(string.format("✅ สร้างโลก ...`
> - ถ้ายังไม่ได้ ใช้ **วิธีที่ 1** แทน

### ขั้นที่ 5: กดเล่น!

1. กดปุ่ม **▶ Play** ด้านบน (หรือกด `F5`)
2. รอประมาณ **30 วินาทีถึง 1 นาที** (โลกใหญ่มาก) ระหว่างนี้ในช่อง Output จะเห็นข้อความ:
   ```
   ⏳ กำลังสร้างภูมิประเทศ...
      ภูมิประเทศ 6%  ...  100%
   ⏳ กำลังสร้างเมือง ปราสาท ท่าเรือ...
   ⏳ กำลังสร้างต้นไม้โลก หมู่บ้านเอลฟ์ ดันเจี้ยน...
   ⏳ กำลังปลูกต้นไม้...
   ✅ สร้างโลก 'FantasyWorld' เสร็จแล้ว
   ```
3. ตัวละครจะเกิดที่ลานน้ำพุกลางเมือง ออกไปผจญภัยได้เลย!

### ✨ ขั้นที่ 5.5: เปิดกราฟิกสวยสุด (แนะนำ)

1. ใน Explorer คลิกที่ **Lighting** แล้วในหน้าต่าง **Properties** หา **Technology** ตั้งเป็น **Future** (แสงและเงาสมจริงที่สุด ไฟทุกดวงมีเงา)
   > สคริปต์พยายามตั้งให้อัตโนมัติ แต่บางเวอร์ชันของ Roblox ต้องตั้งเอง
2. ใน Studio ไปที่ **File → Studio Settings → Rendering** แล้วตั้ง **Quality Level** เป็น **Level 21**
3. ตอนเล่นในเกมจริง กด `Esc` → **Settings** → **Graphics Mode: Manual** แล้วเลื่อน **Graphics Quality** ไปทางขวาสุด
4. จะเลิกเล่นให้กดปุ่ม **■ Stop** (หรือ `Shift + F5`)

### 🎮 ปุ่มควบคุม

| ปุ่ม | ทำอะไร |
|---|---|
| `W A S D` | เดิน |
| `Space` | กระโดด |
| คลิกขวาค้าง + ลากเมาส์ | หมุนกล้อง |
| ลูกกลิ้งเมาส์ | ซูมเข้า/ออก |

### ขั้นที่ 6: บันทึกเกม

- **File → Save to Roblox** เพื่อบันทึกขึ้นบัญชี Roblox (เปิดต่อจากเครื่องไหนก็ได้)
- หรือ **File → Save to File** เพื่อบันทึกเป็นไฟล์ `.rbxl` ในเครื่อง

### ขั้นที่ 7: ชวนเพื่อนมาเล่น

1. **File → Publish to Roblox** ตั้งชื่อเกม แล้วกด **Create**
2. ไปที่ **Home → Game Settings → Permissions** แล้วเปลี่ยนเป็น **Public**
3. กด **Save** จากนั้นส่งลิงก์เกมให้เพื่อน หรือให้เพื่อนค้นชื่อเกมในหน้า Roblox

## 🛠️ ปรับแต่งแมพ

ด้านบนสุดของสคริปต์มีตาราง `CONFIG` แก้ตัวเลขแล้วกด Play ใหม่ได้เลย

| ค่า | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `Seed` | เปลี่ยนเลขแล้วภูเขา ต้นไม้ และหินจะสุ่มตำแหน่งใหม่ | `7` |
| `WorldHalfSize` | ครึ่งหนึ่งของความกว้างโลก | `1536` |
| `TreeCount` | จำนวนต้นไม้ทั่วเกาะ | `750` |
| `ForestTreeCount` | จำนวนต้นไม้เพิ่มในป่ามหัศจรรย์ | `220` |
| `ElderwoodTreeCount` | จำนวนต้นไม้ยักษ์ในป่าโบราณ | `260` |
| `RockCount` | จำนวนก้อนหิน | `180` |
| `DarkTheme` | `true` = ภาพมืด หมอก เดินป่า, `false` = สว่างสดใส | `true` |
| `LeafDetail` | ความละเอียดต้นไม้: `1` = เบาเครื่อง (ประมาณ 24,000 ชิ้นทั้งแมพ), `2` = ปกติ (ประมาณ 39,000 ชิ้น), `3` = ละเอียดมาก (มีกิ่งข้างและพุ่มใบตามข้อกิ่ง) | `2` |
| `DayLengthMinutes` | 1 วันในเกมยาวกี่นาที | `12` |
| `SpawnMonsters` | `false` = ปิดมอนสเตอร์ (เล่น Roleplay อย่างเดียว) | `true` |
| `StartCoins` | เหรียญตอนเริ่มเกม | `0` |

ถ้าอยากปรับละเอียดกว่านี้:
- **ความแรงของมอนสเตอร์** ให้แก้ในตาราง `MONSTER_TYPES` (`hp` = เลือด, `damage` = แรงตี, `speed` = ความเร็ว, `coins` = เหรียญที่ได้)
- **อาวุธ** ให้แก้ในตาราง `WEAPONS` (`damage` = ดาเมจ, `price` = ราคา, `cooldown` = เวลาหน่วงระหว่างโจมตี, `range` = ระยะ)
- **ชื่อร้านค้า** ให้แก้ในตาราง `SHOPS`
- **อาชีพ (ทีม)** ให้แก้ในตาราง `TEAM_DEFS`

### 🌳 อยากได้ต้นไม้/หิน แบบโมเดลสมจริง

สคริปต์สร้างต้นไม้ให้ **ทรงเหมือนต้นจริง** จากชิ้นส่วนพื้นฐาน (กล่อง ทรงกระบอก ลิ่ม):
- **ต้นไม้ใบกว้าง:** ลำต้นเอียงคด แตกกิ่งเป็นทอด ๆ จากกิ่งใหญ่ไปกิ่งเล็ก และมีพุ่มใบที่ปลายกิ่งทุกกิ่ง ทุกต้นทรงไม่ซ้ำกัน
- **ต้นสน:** กิ่งแผ่เป็นชั้นรอบลำต้น ปลายห้อยลง ชั้นล่างกว้าง ชั้นบนแคบ
- **ต้นไม้ยักษ์:** มีรากแผ่ 4 ทิศ

แต่ละชิ้นยังเป็นทรงเรขาคณิต (low-poly)
ส่วนโมเดลที่ดูสมจริงเหมือนเกมดัง ๆ เป็น **MeshPart** ที่ปั้นจากโปรแกรม 3D ถ้ามีโมเดลแบบนั้น สคริปต์จะ **ใช้แทนทั้งแมพให้อัตโนมัติ**

**ขั้นตอน:**
1. ใน Explorer คลิกขวาที่ **ServerStorage** → **Insert Object** → **Folder** แล้วตั้งชื่อว่า `CustomModels`
2. หาโมเดลมาใส่ (เลือกได้ 2 ทาง)
   - **ทาง A: โหลดฟรีจาก Creator Store**
     1. ไปแท็บ **Home** → **Toolbox** → **Models**
     2. ค้นคำว่า `realistic tree`, `pine tree`, `rock`, `leaves` หรือ `bush`
     3. เลือกโมเดลที่มีเครื่องหมาย ✔️ (ผู้สร้างที่ยืนยันตัวตนแล้ว) แล้วคลิกเพื่อใส่ลงเกม
   - **ทาง B: ปั้นเองใน Blender** แล้ว export เป็น `.fbx` หรือ `.obj` จากนั้นใน Studio ใช้ **File → Import 3D**
3. ลากโมเดลไปไว้ในโฟลเดอร์ `CustomModels` แล้ว **เปลี่ยนชื่อ** ตามตารางนี้

| ชื่อโมเดล | ใช้แทน |
|---|---|
| `Tree` | ต้นไม้ทั่วไปทั้งเกาะ |
| `PineTree` | ต้นสนบนภูเขา |
| `AncientTree` | ต้นไม้ยักษ์ในป่าโบราณ |
| `Rock` | ก้อนหิน |
| `LeafCluster` | พุ่มใบของ **ต้นไม้โลก** (ใช้โมเดลพุ่มไม้/ใบไม้) |

4. กด Play สคริปต์จะทำให้เองอัตโนมัติ:
   - ปรับขนาดโมเดล
   - หมุนสุ่มทิศ ต้นไม้จะได้ไม่หน้าตาเหมือนกันหมด
   - วางให้โคนแตะพื้น

> ✅ ใส่แค่บางชื่อก็ได้ อันไหนไม่มี สคริปต์จะสร้างแบบเดิมให้
>
> 🔒 สคริปต์ **ลบ Script ที่แอบติดมากับโมเดลจาก Toolbox ทิ้งอัตโนมัติ** (บางโมเดลมีสคริปต์อันตรายซ่อนอยู่)
>
> ⚡ เลือกโมเดลที่ไม่หนักเกินไป เพราะต้นไม้มีเป็นพันต้น ถ้าเครื่องกระตุกให้ลด `TreeCount`

### อยากให้แมพอยู่ถาวร เพื่อตกแต่งเองด้วยมือ

ปกติแมพจะถูกสร้างใหม่ทุกครั้งที่กด Play และหายไปเมื่อกด Stop ถ้าอยากให้แมพค้างอยู่ในโหมดแก้ไข จะได้ลากย้าย เปลี่ยนสี หรือเพิ่มของเองได้:

1. เปิด **View → Command Bar** (จะมีช่องพิมพ์โผล่ขึ้นด้านล่าง)
2. วางโค้ดทั้งไฟล์ลงในช่องนั้น แล้วกด `Enter`
3. แมพจะโผล่ในโฟลเดอร์ `Workspace → FantasyWorld` ทันที
4. **ลบ Script ใน ServerScriptService ทิ้ง** ไม่อย่างนั้นตอนกด Play สคริปต์จะสร้างแมพใหม่ทับของที่แต่งไว้

> ⚠️ วิธีนี้ได้แค่ตัวแมพ มอนสเตอร์ ดาบ และร้านค้าจะไม่ทำงาน เพราะระบบเกมอยู่ในสคริปต์ที่ลบไป
