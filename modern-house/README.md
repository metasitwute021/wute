# Modern House — รุ่นเพิ่มรายละเอียดภายใน/ภายนอก

โมเดลบ้านโมเดิร์น (OBJ + MTL + ไฟล์ต้นฉบับ Cinema 4D) ที่เพิ่มเฟอร์นิเจอร์ คน
รถ สนามหญ้า และของตกแต่งเข้าไปจากตัวต้นฉบับ

## ไฟล์
| ไฟล์ | คำอธิบาย |
|------|----------|
| `modern-house.obj` | เรขาคณิตหลัก (เดิม 106,296 จุด → ปัจจุบัน 110,368 จุด) |
| `modern-house.mtl` | วัสดุ เพิ่มวัสดุสีล้วนสำหรับเฟอร์นิเจอร์/คน/รถ/หญ้า |
| `modern-house.c4d` | ไฟล์ต้นฉบับ Cinema 4D (ไม่ถูกแก้ไข) |
| `build_details.py` | สคริปต์ Python ที่สร้าง/ต่อ geometry รายละเอียดทั้งหมด |

## ระบบพิกัด
แกน **Y ขึ้น** — พื้นชั้นล่าง `Y=0`, เพดานชั้นล่าง ~`Y=200`
ของในบ้านทุกชิ้นสูงไม่เกิน `Y=188` จึงไม่ทะลุเพดาน

## สิ่งที่เพิ่มเข้าไป (288 วัตถุใหม่)

### โซนห้องครัว (ปีกตะวันตก)
ตู้ล่าง + เคาน์เตอร์สเตนเลส, อ่างล้างจาน + ก๊อกน้ำ, เตา/หัวเตา, เครื่องดูดควัน,
ตู้แขวนผนัง, ตู้เย็น, เกาะกลางครัว + เก้าอี้สตูล 3 ตัว, ชุดโต๊ะอาหาร + เก้าอี้ 4 ตัว,
หม้อ/ขวด/เขียง/ชามผลไม้ และ "คนกำลังทำครัว"

### ห้องนั่งเล่น (ปีกตะวันออก-ใต้)
โซฟา + เบาะ/หมอนอิง, โต๊ะกลาง + หนังสือ, ชั้นทีวี + ทีวี, ชั้นหนังสือพร้อมหนังสือ,
เก้าอี้อาร์มแชร์, โคมไฟตั้งพื้น, ต้นไม้กระถาง, พรม, ภาพแขวนผนัง 3 รูป และคนนั่งบนโซฟา

### ห้องนอน (ปีกตะวันออก-เหนือ)
เตียง (โครง+ที่นอน+ผ้าห่ม+หมอน+หัวเตียง), โต๊ะข้างเตียง 2 ตัว + โคมไฟ + หนังสือ,
ตู้เสื้อผ้า, ตู้ลิ้นชัก + กระจกเงา, โต๊ะทำงาน + เก้าอี้ + หนังสือ + โคมไฟ,
แจกัน/ต้นไม้, พรม, ภาพแขวนผนัง 2 รูป และคนยืนในห้อง

### สนาม/ภายนอก
สนามหญ้า + กอหญ้ากระจาย ~130 กอ, ทางรถเข้า, **รถยนต์** (ตัวถัง+กระจก+ล้อ+ไฟ),
ต้นไม้ใหญ่, พุ่มไม้ และคน 3 คนในสนาม

## สร้างใหม่ได้อย่างไร
สคริปต์จะ *ต่อท้าย* ลงไฟล์ ดังนั้นรันกับ OBJ/MTL ต้นฉบับเท่านั้น
(ไฟล์ในโฟลเดอร์นี้ถูกรันไปแล้ว — อย่ารันซ้ำทับไฟล์เดิม)

```bash
python3 build_details.py   # อ่าน modern-house.obj/.mtl แล้วต่อ geometry เข้าไป
```
