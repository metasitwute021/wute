# mindset_web — เว็บทดสอบ Mindset แบบแตกกิ่ง

โฟลเดอร์นี้ **ไม่เกี่ยวกับ EA เทรด** ในโฟลเดอร์หลัก — เป็นไอเดียโปรเจกต์แยก เก็บไว้เผื่อวันหนึ่งกลับมาทำจริง

| ไฟล์ | คืออะไร |
|------|---------|
| [`ไอเดีย_เว็บทดสอบ_Mindset.md`](./ไอเดีย_เว็บทดสอบ_Mindset.md) | เอกสารไอเดียฉบับเต็ม — แนวคิด, กลไกแตกกิ่ง, สิ่งที่วัดจากพฤติกรรม, JSON schema, สถาปัตยกรรม, กฎหมาย, roadmap |
| [`demo.html`](./demo.html) | เดโมเล่นได้จริง ไฟล์เดียว |

## เปิดเดโมยังไง

ดับเบิลคลิก `demo.html` — จบ ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต ไม่มี dependency ภายนอกสักตัว

## เดโมพิสูจน์อะไรบ้าง

- ✅ **แตกกิ่งจริง** — คลัง 15 ข้อ เจอจริง 9 ข้อ ตอบต่างกันได้คนละเส้นทาง (หน้าผลบอกด้วยว่าข้อไหนที่ไม่ได้เจอเพราะเดินคนละกิ่ง)
- ✅ **เก็บพฤติกรรม** — ข้าม / ย้อนกลับ / เปลี่ยนคำตอบ / ดูคลิปจนจบหรือข้ามที่กี่ % / scroll อ่านถึงกี่ % / เวลาก่อนแตะตัวเลือกแรก
- ✅ **วัด growth mindset จากปฏิกิริยาจริง** — เว็บยิงข้อมูลสวนกลับหลังตอบ แล้วดูว่าผู้ใช้ยอมทบทวนไหม
- ✅ **แยกสาย A (คะแนนจากคำตอบ) ออกจากสาย B (ข้อสังเกตจากพฤติกรรม)** ไม่ยุบเป็นตัวเลขเดียว
- ✅ **โปร่งใส** — โชว์ event log ดิบทั้งหมดให้ผู้ใช้ดูเองที่หน้าผล

## เดโมยัง *ไม่* ทำอะไร

- ไม่มีระบบจ่ายเงินจริง (ปุ่มบริจาคเป็นของปลอม)
- ไม่มี backend — ทุกอย่างอยู่ในหน่วยความจำเบราว์เซอร์ ปิดหน้าต่างแล้วหายหมด ไม่ส่งข้อมูลออกไปไหน
- คะแนนที่ได้ **ยังไม่ใช่ผลทางจิตวิทยาที่เชื่อถือได้** — ข้อคำถามยังไม่ได้ดัดแปลงจาก IPIP อย่างจริงจัง และสัญญาณพฤติกรรมยังไม่ผ่านการ validate (ดู Phase 2 ในเอกสารไอเดีย)

## ถ้าจะทำต่อ เริ่มตรงไหน

โค้ดใน `demo.html` แยกเป็น 3 ส่วนไว้แล้วให้ยกไปทำจริงได้ตรง ๆ:

1. `POOL` — คลังข้อ → ตอนทำจริงย้ายไปฝั่งเซิร์ฟเวอร์ (ห้ามส่งทั้งก้อนมาที่เบราว์เซอร์ ไม่งั้นเปิด DevTools ก็เห็นน้ำหนักคะแนนทุกข้อ)
2. `ENGINE` — `logEvent()` / `scoreState()` / `pickNext()` → ย้ายเป็น API
3. `UI` — เปลี่ยนเป็น React/Next ได้โดยไม่แตะ 2 ส่วนบน
