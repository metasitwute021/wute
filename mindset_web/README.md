# สังเกตการณ์ — เว็บทดสอบ mindset แบบแตกกิ่ง

โฟลเดอร์นี้ **ไม่เกี่ยวกับ EA เทรด** ในโฟลเดอร์หลัก — เป็นโปรเจกต์แยก

เว็บทดสอบนิสัย/mindset ที่ไม่มีชุดคำถามตายตัว คำตอบแต่ละข้อพาไปเจอคำถามคนละชุด
แตกกิ่งจากคลัง 120 ข้อ และ **ไม่ได้วัดแค่คำตอบ** แต่วัดว่าคุณข้ามอะไร ย้อนกลับไปแก้อะไร
อ่านบทความถึงกี่ % และยอมทบทวนคำตอบไหมเมื่อเจอข้อมูลที่สวนกับที่ตอบไป

## 🔧 แก้แล้ว build ใหม่

```bash
python3 build.py           # ตรวจคลังข้อ + build ไป docs/
python3 build.py --check   # ตรวจอย่างเดียว ไม่เขียนไฟล์
```

แก้ **คำถาม** ที่ `items.json` · แก้ **หน้าตาเว็บหรือ engine** ที่ `app.html` · **อย่าแก้ `docs/index.html` ตรง ๆ** เพราะจะโดนทับทุกครั้งที่ build

`build.py` จะไม่ยอม build ถ้าคลังข้อผิดกติกา เช่น เส้นบังคับชี้ไปข้อที่ไม่มีอยู่, แกนไหนมีข้อไม่ถึง 12 ข้อ, ข้อกลับด้านน้อยกว่า 40%, forced-choice น้อยกว่า 12 ข้อ หรือข้อเปิดน้อยกว่า 8 ข้อ

## ✅ เว็บนี้ทำอะไรได้แล้ว

- **แตกกิ่งจริง** — คลัง 120 ข้อ เจอจริง 12–20 ข้อ (จำลอง 500 คน ได้เส้นทางไม่ซ้ำกันเลย 500/500)
- **เลือกข้อถัดไปแบบ adaptive 4 ชั้น** — เส้นบังคับ → โควตาข้อบทความ → โควตาขั้นต่ำต่อแกน → แกนที่หลักฐานน้อยสุด แล้วสุ่มในกลุ่มที่ดีเท่ากัน
- **จบเองได้ก่อนครบ 20 ข้อ** เมื่อทุกแกนข้อมูลพอ
- **เก็บพฤติกรรม** — ข้าม / ย้อนกลับ / เปลี่ยนคำตอบ / scroll อ่านถึงกี่ % / เวลาก่อนแตะตัวเลือกแรก
- **วัด growth mindset จากปฏิกิริยาจริง** — ยิงข้อมูลสวนกลับหลังตอบ แล้วดูว่ายอมทบทวนไหม
- **แยกสาย A (คะแนนจากคำตอบ) ออกจากสาย B (ข้อสังเกตจากพฤติกรรม)** ไม่ยุบเป็นตัวเลขเดียว
- **การ์ดสรุปรวมเต็มจอ** — กดปุ่ม "ดูสรุปรวม" แล้วเห็นทุกอย่างสำคัญในจอเดียว (3 แกนที่เด่นสุด + มุมมองต่อความสามารถ + สิ่งที่ทำระหว่างตอบ) เหมาะกับแคปหน้าจอ ปิดด้วยปุ่มหรือ Esc
- **อ่านผลเป็นประโยค ไม่ต้องเดาจากจุดบนเส้น** — ทุกแกนมีบรรทัดสรุปเช่น "ค่อนไปทาง \u201cวางแผน มีวินัย\u201d" อยู่เหนือแถบ
- **หน้าผลโฟกัสที่คะแนน** — ข้อสังเกตพฤติกรรม / เส้นทางที่เดิน / log ดิบ พับเก็บไว้ กดกางเมื่ออยากดู
- **โปร่งใส** — โชว์ event log ดิบทั้งหมดให้ผู้ใช้ดูเองที่หน้าผล
- รองรับโหมดสว่าง/มืด + ปุ่มสลับ, ออกแบบมาเพื่อจอมือถือเป็นหลัก

## ⛔ ยัง *ไม่* ทำ

- **ไม่มีคลิป** — schema รองรับไว้แล้วแต่ยังไม่ได้ทำ UI เล่นคลิป
- **ไม่มี backend** — ทุกอย่างอยู่ในหน่วยความจำเบราว์เซอร์ ปิดหน้าต่างแล้วหายหมด ไม่ส่งข้อมูลออกไปไหน
- **ไม่มีระบบจ่ายเงินจริง** — ปุ่มบริจาคเป็นของปลอม
- **คะแนนยังไม่ใช่ผลทางจิตวิทยาที่เชื่อถือได้** — ต้องทำ Phase 2 (เก็บข้อมูลจริง 200–500 คน) ก่อน ดู `ITEMS.md`

> ⚠️ ตอนทำระบบจริง **ห้ามส่งคลังข้อทั้งก้อนมาที่เบราว์เซอร์** แบบที่เดโมทำ — เปิด DevTools ก็เห็นน้ำหนักคะแนนทุกข้อ ต้องคำนวณข้อถัดไปฝั่งเซิร์ฟเวอร์และส่งมาทีละข้อ
