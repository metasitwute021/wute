ต้นฉบับคือ [`items.json`](./items.json) — **120 ข้อ** ส่วน `demo.html` เก็บสำเนาที่ `build.py` ฉีดเข้าไปให้

## ⚖️ ลิขสิทธิ์ — อ่านก่อนเพิ่มข้อใหม่

เว็บนี้ตั้งใจจะรับเงิน = **ใช้เชิงพาณิชย์** เพราะฉะนั้นเรื่องลิขสิทธิ์ข้อคำถามไม่ใช่เรื่องเล็ก

| เครื่องมือ | สถานะ | เราทำยังไง |
|-----------|-------|-----------|
| **IPIP** (International Personality Item Pool) | **Public domain** — ตั้งใจให้ใช้ได้ทั้งงานวิจัย **และเชิงพาณิชย์** ไม่มีค่าธรรมเนียม ไม่ต้องขออนุญาต แปลได้ | ✅ ใช้เป็นแกน Big Five — 60 ข้อในคลังนี้ `source: "ipip-adapted"` |
| **Dweck — Implicit Theories of Intelligence Scale** | ไม่มีคำประกาศอนุญาตชัดเจน | ⚠️ **ไม่ลอกถ้อยคำ** — เขียนข้อของเราเองโดยอิง *แนวคิด* growth/fixed (แนวคิดไม่มีลิขสิทธิ์ ถ้อยคำมี) → `source: "original"` |
| **Grit Scale (Duckworth)** | ต้องขออนุญาตสำหรับใช้เชิงพาณิชย์ | ❌ ไม่แตะเลย — วัดความอดทนจาก *พฤติกรรม* แทน (scroll ถึงท้ายบทความ) |
| **SD3 / Dirty Dozen (Dark Triad)** | ไม่มีคำประกาศอนุญาตให้ใช้เชิงพาณิชย์ที่ชัดเจน | ⚠️ **ไม่ลอกถ้อยคำ** — เขียนข้อเองอิงแนวคิด Dark Triad (Paulhus & Williams, 2002) → `source: "original"` |
| **MBTI / 16 Personalities** | มีลิขสิทธิ์และเครื่องหมายการค้า | ❌ ไม่แตะ (และอ่อนทางวิชาการอยู่แล้ว) |

**คำอ้างอิงที่ต้องใส่ในเว็บจริง:**
> ข้อคำถามส่วนบุคลิกภาพดัดแปลงจาก International Personality Item Pool (IPIP) ซึ่งเป็นสาธารณสมบัติ
> — Goldberg, L. R., et al. (2006). *The International Personality Item Pool and the future of public-domain personality measures.* Journal of Research in Personality, 40, 84–96.

> ⚠️ "ดัดแปลงเป็นภาษาไทย" ไม่เท่ากับ "ผ่านการ validate ในบริบทไทย" — การแปลข้อวัดจิตวิทยาข้ามภาษาแล้วค่าทางสถิติเปลี่ยนเป็นเรื่องปกติ ต้องทำ Phase 2 ก่อนจะอ้างว่าแม่น

## 🛡️ กติกาคุณภาพที่ `build.py` บังคับ

รัน `python3 build.py --check` แล้วต้องผ่านทุกข้อ:

| กติกา | เหตุผล |
|-------|--------|
| ทุกแกนมี ≥ 12 ข้อ | ไม่งั้น adaptive engine จะหาข้อถามไม่พอ |
| ข้อ `trait` ต่อแกน ต้องกลับด้าน (`reverse`) ≥ 40% | กัน **acquiescence bias** — นิสัยกด "เห็นด้วย" รัวโดยไม่อ่าน |
| ข้อ `forced` ≥ 12 ข้อ | กัน **social desirability bias** — ข้อที่ทั้งสองตัวเลือก "ดูดีพอกัน" ตอบให้ตัวเองดูดีไม่ได้ |
| ทุก `edges` ต้องชี้ไป id และ optionId ที่มีอยู่จริง | กันกิ่งตาย |
| ทุกข้อต้องมีตัวเลือกที่ให้คะแนนอย่างน้อย 1 ตัว | กันข้อที่ไม่วัดอะไรเลย |
| ข้อเปิด (`opener`) ≥ 8 ข้อ และต้องเป็น `scenario` | คนทำซ้ำจะได้ไม่เจอข้อแรกเดิมทุกครั้ง |
| ข้อแกน `D` ต้องมี `facet` และห้ามผูกกับแกนอื่น | กันคะแนน Big Five ปนกับ Dark Triad |
| แต่ละ facet ของ Dark Triad ต้องมี ≥ 4 ข้อ | ด้านที่ข้อน้อยจะถูกประเมินจากหลักฐานบางเกินไป |
| id ห้ามซ้ำ · แกนและ tag ต้องเป็น O/C/E/A/N/G | กันพิมพ์ผิดเงียบ ๆ |

## 🔑 Scoring key

**ข้อ `trait`** — 5 ตัวเลือก "ไม่ตรงเลย → ตรงมาก" ให้คะแนนแกน `-2 -1 0 +1 +2`
ข้อที่ `reverse: true` กลับทิศเป็น `+2 +1 0 -1 -2` (ข้อความของข้อเขียนในทางลบกับแกน)

ตัวอย่าง `t_c_02` "ฉันมักผัดวันประกันพรุ่งกับงานที่ไม่ชอบ" → `reverse: true` → ตอบ "ตรงกับฉันมาก" = C **−2**

**ข้อ `scenario` / สื่อ** — แต่ละตัวเลือกกำหนดน้ำหนักเองใน `w` และ **ให้คะแนนได้หลายแกนพร้อมกัน**
ตัวอย่าง "รับไว้ก่อน เดี๋ยวหาทางเอา" → `{"A": 2, "C": -1}` (ใจดี แต่แลกกับวินัยตัวเอง)

**คะแนนรวม** คำนวณใน `scoreState()` ของ `demo.html`:
`raw` = ผลรวมน้ำหนัก · `evidence` = จำนวนหลักฐาน · `confidence = evidence / TARGET_EVIDENCE`
แถบในรายงาน normalize ด้วย `raw / (evidence × 2)` — **ไม่ใช่ค่าคงที่** เพื่อไม่ให้คนที่ถูกถามเยอะดูสุดโต่งกว่าคนที่ถูกถามน้อย

## ➕ วิธีเพิ่มหรือแก้ข้อ

1. แก้ `items.json`
2. `python3 build.py` — ตรวจแล้วฉีดเข้า `demo.html` อัตโนมัติ
3. ถ้า validator แดง มันจะบอกว่าข้อไหนผิดตรงไหน และ **ไม่ยอมฉีด**

### รูปแบบข้อ

```json
{
  "id": "t_c_02",
  "type": "trait",            // trait | scenario | video | reading
  "source": "ipip-adapted",   // ipip-adapted | original  ← ต้องตรงความจริง
  "tags": ["C"],              // แกนที่ข้อนี้ตั้งใจวัด (ใช้เลือกข้อถัดไป)
  "reverse": true,
  "prompt": "ฉันมักผัดวันประกันพรุ่งกับงานที่ไม่ชอบ",
  "skippable": true,
  "options": [ { "id": "1", "label": "ไม่ตรงกับฉันเลย", "w": { "C": 2 } } ],
  "edges":  { "a": "s_n_01" },   // ไม่บังคับ — เส้นบังคับไปข้อถัดไป
  "forced": true,                // ไม่บังคับ — ทั้งสองตัวเลือกดูดีพอกัน
  "opener": true                 // ไม่บังคับ — ใช้เป็นข้อแรกของ session ได้
}
```

### ข้อควรระวังตอนเขียนข้อใหม่

- **บริบทไทย** — ที่ทำงานไทย ครอบครัวไทย ไม่ใช่แปลจากฝรั่งตรง ๆ
- **ไม่มีตัวเลือกไหน "ถูก"** — ถ้าอ่านแล้วรู้ว่าควรตอบอะไร ข้อนั้นวัดอะไรไม่ได้
- **ห้ามแตะเรื่องอ่อนไหว** — โรคจิตเวช การทำร้ายตัวเอง ศาสนา การเมือง เพศสภาพ
- เขียน `edges` เฉพาะตอนที่คำตอบนั้น *มีความหมายทางจิตวิทยา* ที่ควรเจาะต่อ ไม่ใช่ใส่ให้ครบ
- ใส่ `opener` ได้เฉพาะข้อที่ **เข้าใจได้เองโดยไม่ต้องอ้างข้อก่อนหน้า** — ข้ออย่าง `s_c_02`
  ("แผนที่วางไว้พังตั้งแต่วันที่ 3") เป็นข้อต่อเนื่อง ห้ามใช้เปิด

## ⚠️ ข้อควรระวังเฉพาะของแกน Dark Triad

แกนนี้อ่อนไหวกว่าแกนอื่นมาก กติกาที่ตั้งไว้และ **ห้ามผ่อน**:

- ข้อคำถามอยู่ในระดับ **พฤติกรรมประจำวัน** เท่านั้น ห้ามแตะอาชญากรรม ความรุนแรง หรือการทำร้ายตัวเอง
- รายงาน**ห้ามใช้คำวินิจฉัย**กับผู้ใช้ ("คุณเป็นไซโคพาธ") — ใช้คำว่า *แนวโน้ม* และบอกเป็นช่วง
  (ต่ำกว่าค่ากลาง / ประมาณค่ากลาง / สูงกว่าเล็กน้อย / สูงกว่าชัดเจน)
- ทุกด้านต้องแสดง **ทั้งข้อดีและข้อเสี่ยง** — คะแนนสูงไม่เท่ากับเป็นคนไม่ดี
- ต้องมีกล่องเตือนเสมอว่า: เป็นแนวโน้มไม่ใช่การวินิจฉัย · คะแนนขยับได้ ·
  **ห้ามใช้ตัดสินคนอื่นหรือคัดคนเข้าทำงาน** · มีช่องทางปรึกษาถ้ากังวล
- ถ้าตอบไม่ถึง 3 ข้อในกลุ่มนี้ ต้องไม่แสดงผลเลย บอกไปตรง ๆ ว่าข้อมูลไม่พอ
- **ขึ้นด้านที่คะแนนสูงสุดก่อนแบบเต็ม แล้วตามด้วยอีกสองด้านแบบย่อ** — โชว์สามด้านเท่ากันหมด
  ผู้อ่านสรุปไม่ได้ว่าตกลงตัวเองเป็นแบบไหน แต่โชว์ด้านเดียวก็ทำให้คิดว่าอีกสองด้านหายไป
- ถ้าด้านที่สูงสุดยังอยู่ในช่วง "ประมาณค่ากลาง" ต้องบอกด้วยว่ามันโดดกว่าอีกสองด้านเพียงเล็กน้อย
- ต้องอธิบายว่า **"ค่ากลาง" คือกลางของสเกล ไม่ใช่ค่าเฉลี่ยของคนจริง** เพราะยังไม่มีข้อมูล norm

## 🦊 สัตว์ประจำตัว — กติกา

สัตว์ 20 ตัวอยู่ในตัวแปร `BEASTS` ใน `app.html` (ไม่ได้อยู่ใน `items.json` เพราะไม่ใช่ข้อคำถาม)
แต่ละตัวมี `t` = ทิศทางของแรงขับในแต่ละมิติ (-1..1) จับคู่ด้วย **projection** ไม่ใช่ระยะใกล้สุด

| กติกา | เหตุผล |
|-------|--------|
| แสดง **ตัวเดียว** เท่านั้น | ให้หลายตัวแล้วมันกลายเป็นดูดวง ไม่ใช่ผลลัพธ์ |
| **ห้ามผูกสัตว์ตัวไหนเข้ากับ psychopathy โดยตรง** | จะอ่านเป็นการวินิจฉัยทางคลินิกทันที มิติ `psyc` ใช้เป็นส่วนประกอบเล็ก ๆ ได้ในความหมาย "ตัดสินใจเย็น" เท่านั้น |
| ต้องมีคำเตือนว่าสัตว์คือ**สัญลักษณ์ของแรงขับ** ไม่ใช่ฉลาก | กันคนเอาไปแปะให้ตัวเองหรือคนอื่น |
| คำบรรยายสัตว์ต้องไม่มีตัวไหน "ดีกว่า" ตัวอื่น | แม้แต่งูกับแมงป่องก็ต้องเขียนให้เป็นแรงขับที่มีเหตุผล |
| ถ้าโปรไฟล์กลาง ๆ (score < .35) ต้องบอกตรง ๆ ว่าเป็นแนวโน้มอ่อน | ไม่ฟันธงเกินข้อมูล |

ถ้าเพิ่มสัตว์ใหม่ ให้รันสคริปต์กระจายตัวก่อน — เกณฑ์คือ **ไม่มีตัวไหนออกเกิน 30%** และ
**ตัวที่ไม่เคยออกเลยต้องไม่เกิน 4 ตัว** (ล่าสุด: ออกครบ 20/20 ตัว ตัวที่บ่อยสุด 14%)

## 🧪 บทเรียน: "หลักฐานครบ 7/7" ไม่เท่ากับ "แม่นขึ้น"

เคยลองไล่ให้ทุกแกนมีหลักฐานครบเกณฑ์ (7/7) ด้วยการเขียนข้อที่วัดหลายแกนพร้อมกัน
แล้วให้ engine เลือกข้อที่ "แถมแกนที่ยังขาด" ได้มากที่สุด **ได้ 7/7 จริง แต่ผลแย่ลง**

วัดด้วยการจำลองคนที่รู้นิสัยจริง 400 คน ทำคนละสองรอบ:

| วิธี | ยาวเฉลี่ย | คลาดเคลื่อนจากตัวจริง | แกนที่หลักฐานเต็ม |
|------|----------|---------------------|------------------|
| เดิม (คลัง 135) | 21.6 | **0.251** | 6.2/7 |
| 26 ข้อ | 24.2 | **0.226** | 7/7 |
| + ข้อหลายแกน + เลือกข้อแบบแถมแกน | 20.2 | 0.292 | 7/7 |
| + ถ่วงหลักฐานตามความแรงน้ำหนัก | 21.9 | 0.372 | 4.9/7 |
| + ถ่วงแบบอ่อน | 20.8 | 0.310 | 7/7 |

**สาเหตุ:** คำตอบเดียวที่กระจายไป 2-3 แกน บอกอะไรเกี่ยวกับแต่ละแกนได้น้อยกว่า
ข้อที่ถามตรง ๆ แกนเดียว ตัวนับหลักฐานขึ้น แต่ข้อมูลจริงต่อแกนลดลง
ซ้ำร้ายตัวนับที่พองทำให้ `allAxesConfident()` สั่งจบเร็วขึ้น (21.6 -> 20.2 ข้อ) ยิ่งได้ข้อมูลน้อยลงไปอีก

**สิ่งเดียวที่ทำให้แม่นขึ้นจริงคือถามเพิ่ม** ไม่ใช่ทำให้ตัวนับสวยขึ้น
`TARGET_EVIDENCE` เป็นแค่ตัวนับว่า "ถามแกนนี้ไปพอหรือยัง" ไม่ใช่มาตรวัดความแม่น
**ห้ามออกแบบย้อนกลับจากตัวเลข 7/7**

ส่วนข้อหลายแกน 24 ข้อที่เขียนไว้ **ยังเก็บไว้ในคลัง** (แต่ปิดการเลือกแบบแถมแกนแล้ว)
เพราะให้ประโยชน์ที่การจำลองวัดไม่ได้: เพิ่มข้อ forced-choice จาก 12 เป็น 25 ข้อ
ซึ่งกัน social desirability bias และเติมคู่แกน E×C กับ A×O ที่เดิมไม่มีเลย
ราคาที่จ่ายคือคลาดเคลื่อนเพิ่มจาก 0.251 เป็น 0.265 ในแบบจำลองที่ *ไม่มี* การตอบให้ตัวเองดูดี

## 🎯 สิ่งที่ยังต้องทำก่อนใช้จริง (Phase 2)

คลังนี้ยัง **ไม่ผ่านการ validate** — สิ่งที่ต้องทำ:

1. เก็บข้อมูล 200–500 คน ให้ทำทั้งคลังนี้และแบบวัดมาตรฐาน
