# สรุปโปรเจกต์ — สำหรับใช้เป็นวัตถุดิบเขียนสคริปต์คลิปสอน n8n

> เอกสารนี้สรุปทุกอย่างที่สร้างขึ้นในโปรเจกต์ "AI Coloring Book Factory" บน n8n
> ใช้ส่งให้ AI เขียนสคริปต์วิดีโอสอนต่อได้ทันที — มีทั้งภาพรวม รายละเอียดทีละโหนด บทเรียนที่เจอจริง และโครงคลิปที่แนะนำ

---

## 1. โปรเจกต์นี้คืออะไร (พูดในคลิป 30 วินาทีแรก)

ระบบอัตโนมัติบน n8n ที่ใช้ **AI Agent 3 ตัวทำงานต่อกันเป็นทอดๆ** เพื่อผลิต **"หนังสือภาพระบายสี" (coloring book)** ขายได้จริงบน Etsy / TPT / Amazon KDP

**ผลลัพธ์ต่อการรัน 1 ครั้ง:**
- ปกภาพสี 1 หน้า (มีชื่อหนังสือเป็นตัวอักษรบนปก)
- หน้าระบายสีขาว-ดำ 5 หน้า (เส้นหนา สไตล์ kawaii โมเดลห้อง isometric)
- รวมเป็นไฟล์ PDF 6 หน้า กระดาษ A4 แนวนอน
- ส่งเข้า Gmail พร้อมข้อความ "UPLOAD KIT" (ชื่อเรื่อง คำโฆษณา ราคา คีย์เวิร์ด) คัดลอกไปลงขายได้เลย

**จุดขายของคลิป:** ไม่ต้องวาดเป็น ไม่ต้องเขียนโค้ดเป็น กดปุ่มเดียวได้สินค้าดิจิทัล 1 ชิ้น ต้นทุนหลักสิบบาท

## 2. ภาพรวมการทำงาน (ใช้ทำ diagram ในคลิป)

```
[3 ทางเริ่มงาน]
 ├─ Manual Trigger (กดปุ่มเอง)
 ├─ Schedule Trigger (ทุกวัน 09:00)
 └─ Chat Trigger (พิมพ์ไอเดียเอง)
          ↓
      [Config] ← ศูนย์รวมการตั้งค่า (จำนวนหน้า / ขนาดภาพ / คุณภาพ)
          ↓
  [Agent 1: Creative Director]  → คิดธีม ตัวละคร ชื่อเรื่อง ฉากแต่ละหน้า
          ↓
  [Agent 2: Prompt Artist]      → แปลงไอเดียเป็น prompt สั่งวาดภาพ
          ↓
  [Agent 3: Art Director QA]    → ตรวจแก้ prompt ก่อนจ่ายเงินสร้างภาพ
          ↓
  [Build Page List]             → แตกเป็นรายการงาน 6 ภาพ
          ↓
  [Loop] → [Generate Image (gpt-image-1)] → [Attach Binary] ↺ วนจนครบ
          ↓
  [Collect Pages] → เรียงลำดับ ปก → หน้า 1-5
          ↓
  [Build PDF + Email Pack]      → รวมเล่ม PDF ด้วย JavaScript ล้วน
          ↓
  [Send Gmail]                  → ส่งเมล + แนบ PDF + ภาพปก
```

**จำนวนโหนดทั้งหมด:** 18 โหนด (รวมโน้ตอธิบาย 4 อัน)

## 3. รายละเอียดทีละโหนด (เนื้อหาหลักของคลิปสอน)

### 3.1 กลุ่ม Trigger — 3 ทางเริ่มงาน

| โหนด | ชนิด | สอนอะไรได้ |
|---|---|---|
| Manual Trigger | `manualTrigger` | โหนดพื้นฐานที่สุด ใช้ทดสอบ |
| Schedule Trigger | `scheduleTrigger` | ตั้งเวลาอัตโนมัติ (ตั้งไว้ทุกวัน 09:00) สอนเรื่อง workflow ต้องกด Active ถึงจะทำงานจริง |
| Chat - พิมพ์ไอเดียของคุณ | `@n8n/n8n-nodes-langchain.chatTrigger` | ช่องแชทให้ผู้ใช้พิมพ์ไอเดียเอง (public chat) — พิมพ์ไทยก็ได้ AI แปลงเป็นคอนเซ็ปต์เอง |

**ประเด็นสอน:** trigger หลายตัวต่อเข้าโหนดเดียวกันได้ ไม่ต้องสร้าง workflow แยก

### 3.2 Config — โหนด Set ที่เป็นหัวใจของการปรับแต่ง

ชนิด: `n8n-nodes-base.set` (เปิด **Include Other Fields** เพื่อให้ข้อความจากแชทไหลผ่านไปได้)

| ตัวแปร | ค่าปัจจุบัน | หน้าที่ |
|---|---|---|
| `num_pages` | 5 | จำนวนหน้าระบายสี (ไม่รวมปก) |
| `image_size` | 1536x1024 | ขนาดภาพ แนวนอนตรงกับ A4 landscape |
| `image_quality` | high | คุณภาพภาพ (low / medium / high) |

**ประเด็นสอนที่สำคัญมาก:** นี่คือแนวคิด "รวมค่าตั้งไว้ที่เดียว" — อยากเปลี่ยนจำนวนหน้าจาก 5 เป็น 10 แก้ตัวเลขเดียว ระบบทั้งเส้นปรับตามเอง ไม่ต้องไล่แก้ทีละโหนด **เป็นบทเรียนออกแบบ workflow ที่ควรเน้นในคลิป**

### 3.3 AI Agents 3 ตัว — หัวใจของระบบ

ทั้ง 3 ตัวเป็นโหนด **HTTP Request** ยิงตรงไปที่ `https://api.openai.com/v1/chat/completions`
ใช้โมเดล `gpt-4.1-mini` เปิดโหมด `response_format: json_object` เพื่อบังคับให้ตอบเป็น JSON

| Agent | อุณหภูมิ (temperature) | หน้าที่ |
|---|---|---|
| **1. Creative Director** | 1.0 (สูง = สร้างสรรค์) | สุ่มธีมจากคลัง 22 ธีม, เลือกตัวละคร (สลับกันระหว่างสัตว์ / คนตัวจิ๋ว / คนคู่กับสัตว์), ตั้งชื่อเรื่อง, คิดฉาก 5 หน้าที่ไม่ซ้ำกัน, เขียนคำโฆษณา + คีย์เวิร์ดขายของ |
| **2. Prompt Artist** | 0.7 (กลาง) | แปลงไอเดียแต่ละฉากเป็น prompt ภาษาอังกฤษละเอียด แล้วต่อท้ายด้วย "บล็อกสไตล์ล็อก" ที่เขียนตายตัว |
| **3. Art Director QA** | 0.2 (ต่ำ = เป๊ะ) | ตรวจ prompt ทุกอันตาม checklist แล้วแก้เองเลย ไม่ใช่แค่รายงาน |

**เทคนิคที่ควรสอน 3 อย่าง:**

1. **การใส่ random seed** — ในข้อความส่งให้ Agent 1 มี `Math.floor(Math.random() * 1000000)` + วันเวลาปัจจุบัน เพื่อบังคับให้ AI ไม่เลือกธีมเดิมซ้ำๆ (ถ้าไม่ใส่ AI มักเลือกตัวแรกๆ ในรายการเสมอ)

2. **"บล็อกสไตล์ล็อก" (locked style block)** — ข้อความสไตล์ที่ต่อท้าย prompt ทุกอันแบบเป๊ะๆ ทำให้ภาพทุกหน้าออกมาเป็นชุดเดียวกัน เช่น
   > "Isometric 3D room diorama scene, cute kawaii chibi style, ... thick bold black outlines, pure black and white line art, clean white background, no shading, no gray fill, no color, no text, landscape orientation, coloring book page."

   สอนได้ว่า: **prompt ที่ดีไม่ใช่แค่บรรยายภาพ แต่ต้องล็อกสไตล์ไว้ด้วย** ไม่งั้นภาพแต่ละหน้าจะคนละเรื่อง

3. **AI ตรวจงาน AI (QA Agent)** — Agent 3 ทำหน้าที่เดียวคือหาข้อผิดพลาดของ Agent 2 ก่อนที่จะเสียเงินสร้างภาพ เช่น กันไม่ให้มีคำเรียกสี (golden, blue) หลุดเข้าไปในหน้าที่ต้องเป็นขาว-ดำ **จุดนี้เป็นแนวคิดขั้นสูงที่คนทำ n8n ส่วนใหญ่ยังไม่ทำกัน — เป็นไฮไลต์ของคลิปได้**

### 3.4 Build Page List — โหนด Code ตัวแรก

แปลงคำตอบ JSON จาก Agent 3 ให้กลายเป็น "รายการงาน" 6 รายการ (ปก 1 + หน้า 5) แต่ละรายการมี prompt, ชื่อไฟล์, ลำดับที่

**ประเด็นสอน:** AI บางครั้งตอบมาพร้อมรั้ว ` ```json ` ครอบ โค้ดจึงมีบรรทัดตัดรั้วทิ้งก่อน `JSON.parse` — เป็นบั๊กที่มือใหม่เจอบ่อยมาก

### 3.5 Loop Over Images + Generate Image + Attach Binary

- **Loop Over Images** (`splitInBatches`, batch size = 1) — วนสร้างภาพทีละใบ ไม่ยิงพร้อมกัน เพื่อกันโดน rate limit
- **Generate Image** — HTTP Request ไปที่ `https://api.openai.com/v1/images/generations` โมเดล `gpt-image-1`
  - ตั้ง timeout 5 นาที (ภาพ quality high ใช้เวลานาน)
  - ตั้ง retry 3 ครั้ง
  - ตั้ง `onError: continueRegularOutput` — **สำคัญมาก** ทำให้ภาพใบเดียวพังไม่ทำให้ทั้งงานล้ม
- **Attach Binary** — แปลง base64 ที่ OpenAI ส่งกลับมาให้เป็นไฟล์ภาพจริง ถ้าล้มเหลวก็เก็บข้อความ error ไว้รายงานในอีเมลแทน

**ประเด็นสอน:** การวนลูปใน n8n ต้องต่อสายกลับเข้าโหนด Loop เสมอ และ output ของโหนด Loop มี 2 ทาง (done / loop) — คนมือใหม่ต่อสลับกันบ่อยมาก

### 3.6 Build PDF + Email Pack — โหนด Code ที่ยากที่สุด

รวมภาพทั้งหมดเป็นไฟล์ PDF **ด้วย JavaScript ล้วน ไม่ใช้ library ภายนอก ไม่ใช้บริการเสียเงิน**

หลักการ: JPEG สามารถฝังลงไฟล์ PDF ได้ตรงๆ ผ่านตัวกรอง `/DCTDecode` โค้ดจึงอ่านขนาดภาพจาก header ของ JPEG เอง แล้วประกอบโครงสร้าง PDF (Catalog / Pages / XObject / Content stream / xref) ขึ้นมาเป็นไบต์

**ทำไมถึงสำคัญ:** เวอร์ชันแรกของระบบอื่นๆ มักใช้บริการแปลง HTML เป็น PDF แบบเสียเงิน (เช่น PDFShift) แต่วิธีนี้ฟรี ไม่ต้องสมัครอะไรเพิ่ม และใช้ได้ทั้ง n8n Cloud และ self-hosted

**ประเด็นสอน:** โหนด Code ใน n8n เขียน JavaScript ได้เต็มรูปแบบ รวมถึงใช้ `Buffer` และ `this.helpers.prepareBinaryData()` เพื่อสร้างไฟล์แนบ

พร้อมกันนี้โหนดยังประกอบข้อความอีเมลรูปแบบ UPLOAD KIT:
```
====== 🎨 COLORING BOOK UPLOAD KIT ======
[TITLE] ...
[DESCRIPTION] ...
[ART THEME] / [MAIN CHARACTER] / [PAGES] / [PRICE] / [SEARCH KEYWORDS]
[FILE] / [PREVIEW/COVER]
```

### 3.7 Send Gmail

โหนด `n8n-nodes-base.gmail` ส่งเมลไปที่ผู้รับ พร้อมแนบ 2 ไฟล์: `data` (PDF) และ `cover` (ภาพปก)
หัวข้ออีเมลจะขึ้น ⚠️ อัตโนมัติถ้ามีภาพเจนไม่สำเร็จ

**ประเด็นสอน:** Gmail ต้องเชื่อมผ่าน **OAuth2** ฝัง API key ในไฟล์ไม่ได้ (ต่างจาก OpenAI) — เป็นความแตกต่างที่ควรอธิบายในคลิป

## 4. บทเรียนสำคัญที่ได้จากการทำจริง (เนื้อหาที่ทำให้คลิปมีคุณค่า)

### 4.1 เรื่อง API Key และความปลอดภัย
- ไฟล์ workflow ทำ 2 เวอร์ชัน: เวอร์ชันฝัง key จริง (ใช้เอง ห้ามแชร์) กับเวอร์ชัน placeholder (เก็บบน GitHub ได้)
- **เหตุผล:** GitHub และ OpenAI มีระบบสแกน key อัตโนมัติ ถ้าอัปโหลด key จริงขึ้นที่สาธารณะ key จะถูกระงับทันที
- **ข้อคิดสำหรับคลิป:** สอนเรื่องนี้ด้วยจะทำให้คลิปดูมืออาชีพ คนสอน n8n ส่วนใหญ่ไม่พูดถึง

### 4.2 บัญชี OpenAI API ≠ ChatGPT Plus
ปัญหาที่เจอจริงระหว่างทดสอบ: workflow ขึ้น error `"You have no credits remaining"`
- บัญชี API ที่ platform.openai.com ใช้ระบบ **เติมเงินล่วงหน้า** แยกกระเป๋าคนละใบกับ ChatGPT Plus รายเดือน
- ต่อให้จ่าย ChatGPT Plus อยู่ ก็ต้องเติมเครดิต API แยกต่างหาก
- แนะนำให้เปิด Auto-recharge กันเงินหมดกลางทาง
- **นี่คือปัญหาอันดับ 1 ที่มือใหม่เจอ ควรมีในคลิปแน่นอน**

### 4.3 gpt-image-1 ต้อง Verify Organization
โมเดลสร้างภาพของ OpenAI ใช้ไม่ได้จนกว่าจะยืนยันตัวตนองค์กร (ถ่ายบัตรประชาชน/พาสปอร์ต) ที่ Settings → Organization → Verify Organization

### 4.4 ตารางเปรียบเทียบต้นทุนตามคุณภาพภาพ

| image_quality | ต้นทุนต่อชุด (6 ภาพ) | เหมาะกับ |
|---|---|---|
| low | ~$0.11 (~4 บาท) | ทดสอบระบบ |
| medium | ~$0.43 (~15 บาท) | ใช้งานทั่วไป |
| high | ~$1.50 (~55 บาท) | งานขายจริง คมชัดสุด |

**ทริกที่ค้นพบ:** ตั้งปกเป็น high (เพราะเป็นภาพโชว์ตอนขาย) ส่วนหน้าในเป็น medium ก็ได้ ประหยัดไปเยอะ

### 4.5 การออกแบบให้ระบบ "ไม่ล้มทั้งชุด"
ถ้าภาพใบใดใบหนึ่งสร้างไม่สำเร็จ ระบบจะ:
1. ทำงานต่อจนจบ ไม่หยุดกลางทาง
2. สร้าง PDF จากหน้าที่สำเร็จเท่านั้น
3. เขียนคำเตือนในอีเมลว่าหน้าไหนหาย **พร้อมสาเหตุที่ OpenAI ตอบกลับมา** และแนะนำวิธีแก้ (เช่น "เครดิตหมด เติมเงินที่ Billing")

**ประเด็นสอน:** นี่คือแนวคิด error handling ที่ทำให้ระบบอัตโนมัติใช้งานได้จริง ไม่ใช่แค่ทำงานได้ตอนทุกอย่างสมบูรณ์

## 5. โครงคลิปที่แนะนำ (ปรับได้ตามต้องการ)

### แบบคลิปเดียวจบ (20-25 นาที)
| ช่วง | เวลา | เนื้อหา |
|---|---|---|
| 1 | 0:00-1:30 | Hook: โชว์ผลลัพธ์ก่อน — เปิดอีเมลที่มี PDF หนังสือระบายสี 6 หน้า บอกว่านี่มาจากการกดปุ่มเดียว |
| 2 | 1:30-3:00 | เตรียมของ: บัญชี n8n, OpenAI API key + เติมเครดิต + Verify Organization, Gmail |
| 3 | 3:00-5:00 | ภาพรวม workflow ทั้งเส้น (โชว์ diagram) |
| 4 | 5:00-8:00 | สร้าง Trigger 3 แบบ + โหนด Config (เน้นแนวคิดรวมค่าตั้งไว้ที่เดียว) |
| 5 | 8:00-14:00 | สร้าง AI Agent 3 ตัว — อธิบาย system prompt, temperature, บล็อกสไตล์ล็อก, random seed |
| 6 | 14:00-18:00 | Loop สร้างภาพ + โหนด Code + การจัดการ error |
| 7 | 18:00-21:00 | รวม PDF + ส่ง Gmail |
| 8 | 21:00-24:00 | รันจริงให้ดู + เปิดอีเมลดูผลลัพธ์ + สรุปต้นทุน + ทริกประหยัดเงิน |

### แบบซีรีส์ (แนะนำถ้าอยากได้ยอดวิวสะสม)
1. **EP1: รู้จัก n8n + เตรียม API** (8 นาที) — สมัคร เติมเงิน Verify Organization
2. **EP2: สร้าง AI Agent ตัวแรก** (12 นาที) — Trigger, Config, HTTP Request ยิง OpenAI, บังคับให้ตอบ JSON
3. **EP3: ต่อ Agent หลายตัว + เทคนิค prompt** (15 นาที) — บล็อกสไตล์ล็อก, QA Agent, random seed
4. **EP4: สร้างภาพด้วย AI + วนลูป** (12 นาที) — gpt-image-1, Loop, จัดการ binary, error handling
5. **EP5: รวมเล่ม PDF + ส่งเมลอัตโนมัติ** (12 นาที) — โหนด Code, Gmail OAuth
6. **EP6: เอาไปขายจริง + ประหยัดต้นทุน** (10 นาที) — UPLOAD KIT, Etsy/TPT/KDP, เทียบ quality
