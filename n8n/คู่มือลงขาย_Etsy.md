# 🛒 คู่มือเชื่อม Etsy — ลงขายอัตโนมัติจาก n8n

เอกสารนี้ใช้คู่กับ `AI_Coloring_Book_Factory.json` (workflow หลัก) และ `Etsy_Auth_Helper.json` (ตัวช่วยขอสิทธิ์ ใช้ครั้งเดียว)

---

## ระบบทำอะไรให้บ้าง

หลังสร้างหนังสือระบายสีเสร็จ ระบบจะ:
1. สร้าง **ร่างสินค้า (draft listing)** ในร้าน Etsy ของคุณ พร้อมชื่อสินค้า คำโฆษณา แท็ก และราคา ที่ AI เขียนให้
2. อัปโหลด **ภาพปก** เป็นรูปสินค้า
3. อัปโหลด **ไฟล์ PDF** เป็นไฟล์ที่ลูกค้าจะดาวน์โหลด
4. ส่งลิงก์ร่างสินค้ามาในอีเมลให้คุณกดตรวจและเปิดขาย

> **ทำไมเป็นร่าง (draft) ไม่เปิดขายเลย?**
> เพราะการเปิดขายคือการเผยแพร่สินค้าออกสู่สาธารณะ และ Etsy คิดค่าลงสินค้า **$0.20 ต่อชิ้น** ทันทีที่เปิดขาย
> ระบบจึงหยุดที่ร่างไว้ให้คุณตรวจก่อนเสมอ — ถ้าอยากให้เปิดขายเองอัตโนมัติ ตั้ง `etsy_publish = true` ในโหนด Config

## ⚠️ ก่อนเริ่ม: สิ่งที่ต้องมี

| สิ่งที่ต้องมี | หมายเหตุ |
|---|---|
| ร้านค้า Etsy ที่เปิดแล้ว | ต้องเปิดร้าน (Shop) ให้เสร็จก่อน ยังไม่ต้องมีสินค้า |
| แอป Etsy Developer ที่ได้รับอนุมัติ | ขอที่ https://www.etsy.com/developers/register — **Etsy ใช้เวลาพิจารณาหลายวันถึงหลายสัปดาห์** ต้องกรอกว่าจะใช้ทำอะไร (ตอบตามจริงว่า "automate listing my own digital products") |
| n8n ที่กด Active ได้ | ตัวช่วยขอสิทธิ์ต้องใช้ Webhook ซึ่งทำงานเฉพาะตอน workflow เป็น Active |

**ข้อควรรู้:** ถ้ายังไม่ได้รับอนุมัติแอปจาก Etsy จะยังลงขายอัตโนมัติไม่ได้ — ระหว่างรอ ให้ตั้ง `etsy_enabled = false` ไปก่อน ระบบจะสร้าง PDF ส่งเข้าเมลตามปกติ แล้วคุณลงขายเองด้วยมือ (ข้อความ UPLOAD KIT ในอีเมลมีชื่อ/คำโฆษณา/แท็ก ให้คัดลอกวางได้เลย)

## ขั้นตอนที่ 1 — ขอสิทธิ์เข้าถึงร้าน (ทำครั้งเดียว)

### 1.1 Import ตัวช่วย
Import ไฟล์ `Etsy_Auth_Helper.json` เข้า n8n (คนละ workflow กับตัวหลัก)

### 1.2 เอา URL ปลายทางไปใส่ในแอป Etsy
1. ในไฟล์ตัวช่วย เปิดโหนด **Webhook (รับ code จาก Etsy)** → คัดลอก **Production URL**
   (หน้าตาประมาณ `https://ชื่อคุณ.app.n8n.cloud/webhook/etsy-callback`)
2. ไปที่ https://www.etsy.com/developers/your-apps → เลือกแอปของคุณ
3. วาง URL นั้นในช่อง **Callback URL** แล้วบันทึก
4. คัดลอก **Keystring** ของแอปเก็บไว้ (นี่คือ `etsy_keystring`)

### 1.3 กรอกค่าและกดขอสิทธิ์
1. เปิดโหนด **Etsy Auth Config** กรอก 2 ค่า:
   - `etsy_keystring` = Keystring จากข้อ 1.2
   - `redirect_uri` = Production URL จากข้อ 1.2 (ต้องตรงกันเป๊ะ)
2. **กดปุ่ม Active** เปิด workflow ตัวช่วยนี้ (สำคัญ ถ้าไม่เปิด Webhook จะไม่ทำงาน)
3. กด Execute ที่โหนด **1. สร้างลิงก์ขอสิทธิ์** → จะได้ค่า `auth_url`
4. คัดลอก `auth_url` ไปเปิดในเบราว์เซอร์ → ล็อกอิน Etsy → กด **Allow Access**

### 1.4 รับค่าที่ได้
หน้าเว็บจะแสดงผลลัพธ์ให้ทันที:
```json
{
  "etsy_refresh_token": "12345678.xxxxxxxxxxxxxxx",
  "etsy_shop_id": "12345678",
  "หมวดหมู่ที่แนะนำ_เลือก1อันใส่_etsy_taxonomy_id": [
    { "taxonomy_id": 66, "path": "Paper & Party Supplies > Coloring Books" }
  ]
}
```
คัดลอกเก็บไว้ทั้งหมด แล้ว **ปิด Active** ของ workflow ตัวช่วยได้เลย (ใช้อีกครั้งเมื่อไม่ได้รันระบบเกิน 90 วัน)

## ขั้นตอนที่ 2 — กรอกค่าลงใน workflow หลัก

เปิด `AI Coloring Book Factory` → ดับเบิลคลิกโหนด **Config** → กรอก 5 ค่านี้:

| ช่อง | ใส่อะไร | ค่าเริ่มต้น |
|---|---|---|
| `etsy_enabled` | เปิด/ปิดการลงขาย | `true` |
| `etsy_keystring` | Keystring จากแอป Etsy | `YOUR_ETSY_KEYSTRING` |
| `etsy_refresh_token` | ค่าที่ได้จากขั้นตอนที่ 1 | `YOUR_ETSY_REFRESH_TOKEN` |
| `etsy_shop_id` | เลขร้านที่ได้จากขั้นตอนที่ 1 | `YOUR_ETSY_SHOP_ID` |
| `etsy_taxonomy_id` | เลขหมวดหมู่ที่เลือกจากรายการ | `0` |

ค่าที่ปรับเพิ่มได้:

| ช่อง | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `etsy_price` | ราคาขาย (สกุลเงินตามที่ตั้งไว้ในร้าน) | `3.5` |
| `etsy_quantity` | จำนวนที่ขายได้ (สินค้าดิจิทัลใส่เยอะได้) | `999` |
| `etsy_publish` | `true` = เปิดขายทันทีอัตโนมัติ (เสีย $0.20 ทันที), `false` = หยุดที่ร่าง | `false` |

**เสร็จแล้วกด Test workflow ได้เลย** — รอ 3–6 นาที จะได้อีเมลที่มีลิงก์ร่างสินค้า Etsy ต่อท้าย

## สิ่งที่ระบบจัดการให้อัตโนมัติ (ไม่ต้องทำเอง)

| เรื่อง | ระบบทำอะไร |
|---|---|
| **ชื่อสินค้า** | ประกอบชื่อหนังสือ + คำค้นยอดนิยม ตัดให้ไม่เกิน 140 ตัวอักษรตามกฎ Etsy และตัดอักษรพิเศษ/อิโมจิที่ Etsy ไม่รับออก |
| **แท็ก** | ดึงคีย์เวิร์ดที่ AI คิดให้ + เติมแท็กมาตรฐาน แล้วกรองตามกฎ Etsy (สูงสุด 13 อัน อันละ ≤20 ตัวอักษร ห้ามซ้ำ ห้ามอักขระแปลก) |
| **คำโฆษณา** | คำโฆษณาจาก AI + บล็อกมาตรฐาน (WHAT YOU GET / INSTANT DOWNLOAD / HOW TO USE) |
| **การต่ออายุสิทธิ์** | access token ของ Etsy หมดอายุทุก 1 ชั่วโมง ระบบต่ออายุให้เองทุกครั้งที่รัน และ**เก็บ refresh token ตัวใหม่ที่ Etsy หมุนให้อัตโนมัติ** |
| **เมื่อ Etsy ล่ม/พัง** | ระบบไม่ล้มทั้งงาน — ยังส่งอีเมลพร้อม PDF ให้ตามปกติ แล้วเขียนสาเหตุที่ลงขายไม่สำเร็จไว้ในอีเมล |

## ❓ แก้ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| อีเมลขึ้น `⚠️ ยังไม่ได้ลงขาย เพราะยังตั้งค่าไม่ครบ` | ยังกรอกค่า etsy_* ในโหนด Config ไม่ครบ — อีเมลจะบอกว่าขาดช่องไหน |
| `ขอ access token ไม่สำเร็จ` / 401 | refresh token หมดอายุ (เกิน 90 วันไม่ได้ใช้) หรือกรอกผิด → กลับไปทำขั้นตอนที่ 1 ใหม่ |
| `สร้าง listing ไม่สำเร็จ` + พูดถึง taxonomy | `etsy_taxonomy_id` ผิดหรือยังเป็น 0 → ใช้เลขจากรายการที่ตัวช่วยแนะนำ |
| Webhook ไม่ตอบตอนกด Allow Access | ลืมกด **Active** ที่ workflow ตัวช่วย หรือ Callback URL ในแอป Etsy ไม่ตรงกับ `redirect_uri` เป๊ะ |
| `state ไม่ตรง` | เปิดลิงก์เก่าที่หมดอายุ → กด Execute โหนด "1. สร้างลิงก์ขอสิทธิ์" ใหม่ แล้วใช้ลิงก์ล่าสุด |
| ร่างสินค้าสร้างได้ แต่ไม่มีรูป/ไฟล์ | อีเมลจะเขียนเตือนไว้ — เข้าไปอัปโหลดเองในหน้าแก้ไขสินค้าได้ (ไฟล์ทั้งสองแนบมาในอีเมลแล้ว) |
| อยากหยุดลงขายชั่วคราว | โหนด Config → `etsy_enabled = false` |

## 🔒 ความปลอดภัย

- `etsy_keystring` และ `etsy_refresh_token` ถูกเก็บในโหนด Config ของ workflow — **ไฟล์ที่มีค่าเหล่านี้ห้ามแชร์หรืออัปโหลดขึ้นที่สาธารณะ** เพราะเปิดให้คนอื่นสร้าง/แก้สินค้าในร้านคุณได้
- เวอร์ชันที่เก็บบน GitHub ในโฟลเดอร์นี้เป็น placeholder ทั้งหมด ไม่มีค่าจริง
- ถ้าเผลอทำหลุด: เข้า https://www.etsy.com/developers/your-apps แล้วสร้าง Keystring ใหม่ (ของเก่าจะใช้ไม่ได้ทันที)
